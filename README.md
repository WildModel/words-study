# WordNote 单词手记

基于两个原始 HTML 词库的 iPhone PWA。使用 HTTPS 部署后，在 iPhone 的 Safari 中打开，点击分享，再选择“添加到主屏幕”。首次联网打开并等待词库加载后，可离线学习。

选择词库、级别、顺序或随机，以及每组数量开始学习。每张卡片查看答案后选择记忆程度；到期词会出现在今日复习中，不熟悉的词也可以随时复习。复习间隔参考间隔重复原则，依评分调整，并非精确预测个人记忆曲线。

学习记录保存在当前浏览器的本地存储中，不会自动跨设备同步；清除网站数据会删除记录。可在“我的”页面导出和导入备份。原始 HTML 的学习记录不会自动导入。

本地预览：在此目录执行 `python3 -m http.server 8000`，访问 `http://localhost:8000/`。Service Worker 需要 HTTPS 或 localhost。
